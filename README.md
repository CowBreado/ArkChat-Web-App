# ArkChat-Web-App (Personal Project)
ArkChat is a lightweight Flask messaging app where users can register, log in, find users, and exchange private messages. Passwords are hashed before database storage. Built with Python and Flask, the project demonstrates full-stack development, database management, and application deployment. It is currently hosted via Render and Neon for PostgreSQL.

# Progress
ArkChat is a work-in-progress system and current does not support real-time chat automatic updation. A temporary fix at the moment is by reloading. SocketIO is planned to be implemented to solve this current problem for the next iteration.
